# Devs Client

Fabric client for **Minecraft 1.21.11**. This is a UI-only base: ClickGUI, HUD, themes, configs, and the module system with empty Combat / Misc / Render / Visuals categories so 6b6t features can be added later.

## Build

```bash
./gradlew build
./gradlew runClient
```

The remapped jar lands in `build/libs/devsclient-1.0.0.jar`.

Right Shift opens ClickGUI in-game. Open chat and drag HUD elements to move them; scroll to resize.
